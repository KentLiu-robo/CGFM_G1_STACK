# 已知问题

按对实验的影响排序。这些都是真机运行中实际遇到的，不是理论推测；**“未实现”表示还没有修复**。

## 1. WiFi 下 IMU 丢包 → SLAM 报错（最主要的问题）

Jetson 本机的 `/livox/imu` 是完整的 200 Hz，经 WiFi/DDS 到开发机后只剩约 150–165 Hz，间隔缺口 20–70 ms。带雷达负载时实测：Jetson↔路由器、开发机↔路由器的 ping 都不丢包，同频率的裸 UDP 只丢 0.3%，但经 DDS 的 IMU 丢约 22%，丢包发生在 DDS 层（雷达每帧约 380 KB，被拆成约 270 个 1400 B 分片，和 IMU 走同一套传输）。后果：

- IMU 预积分报 `failureDetected`，常在机器人一转身时开始，之后反复出现，定位跳变；
- 雷达数据积压后，`feature_extraction_node` 可能在 `assert(plannerPoints->size()>0)` 处崩溃；
- 出现后只能重启导航栈，SLAM 不会自己恢复。

候选办法（未实施）：IMU 改走 UDP 中转绕开 DDS；Jetson 上给点云降采样；把那个 `assert` 改成跳过该帧；实验时开发机用网线接路由器（可以明显减少）。

## 2. 挪动机器人之后 SLAM 垂直方向发散

一次遥控走动之后，`/state_estimation` 的 z 漂到约 -10 m（平地上应接近 0），`failureDetected` 从 0 涨到每分钟 4–16 次，而机器人静止。terrain 分析和 localPlanner 都依赖相对高度，会直接影响避障。**处理：把机器人放到想要的起点、站稳，teardown + bringup 重启整个导航栈**；重启后静止位姿应 x、y 波动 < 0.02 m、z ≈ -0.02、`failureDetected = 0`。凡是开跑前挪过机器人，都重启一次再开跑。

## 3. 相机画面卡在同一帧

Jetson 上 RealSense 推流服务卡住，`health_check.sh` 只检查端口，**检查不出来**。处理：完整重启导航栈。确认画面在更新：连接推流端口数 12 s 内的“不同帧”，正常约彩色 10 fps、深度 8 fps、最大间隔 < 0.25 s。

## 4. 锁定走向目标时被局部规划器夹住（未实现恢复）

日志 `PATH NOT FOUND -- all directions blocked, rotating in place (no reverse)`：机器人原地转了约 150 s，净位移 < 0.3 m，pathFollower 路径只有 2 个点，路径可用率从 1% 逐渐升到 91%。排查结论**不是 SLAM 发散**（`failureDetected = 0`、位姿静止且稳定、z 正常）。点云显示机器人周围 0.14–0.4 m 内有高度 0.4–0.7 m 的障碍（吧台高脚椅的脚圈、桌腿、纸箱），而前方相机的盲区约 0.7 m，所以画面看着“前方是空的”。局部规划器配置 `twoWayDrive = false`，被夹住后只能原地转、不能倒车。主脚本在锁定阶段没有“长时间没进展”的恢复（只有探索阶段的 frontier 停滞黑名单，且要求还有 frontier）。开跑前请清掉起点和路线上 0.6 m 内的低矮障碍。

## 5. 裁剪图复核会拒绝真目标

复核是选择题。小而糊的网状垃圾桶（裁剪图常只有 40–80 px）会被答成 `box`（连续 4–6 次）；放在桌上的桶，裁剪图带着桌面，被答成 `table`（18 次）；裁剪图小于 48 px 时复核被跳过、按检测器标签接受，变大之后反而进入复核被拒。已有的缓解：终身脚本的**回忆规则**（已找到过的目标绕过复核）和**投票规则**（同一节点被选中 ≥ 3 次、标签等于目标、答案没有冲突类别就接受）。`table` 等明确冲突的答案仍然否决，尚未做“更清楚的裁剪图”。

## 6. 探索耗尽后没有自动放弃目标（终身脚本，未实现）

房间探索完（`frontiers = 0`）仍没找到目标时，脚本不做任何事，只是每秒打一行 tick，直到手动 `stop`。计划：frontier 连续约 10 个 tick 为 0 就把该目标记为“没找到”，自动切下一个（这样后面的目标可以触发回忆）。

## 7. 其他

- **WebRTC 静默卡死**：进程活着、日志没有报错，但 `/cmd_vel`、`/hello`、`/liedown` 都不执行，表现为机器人跑着跑着突然停住（常在转弯到一半）。处理：重启 `unitree_control`，再调一次 `/hello` 确认。
- **玻璃隔间在障碍图里形成大片扇形黑区**：深度相机透过玻璃看到里面和后面的东西（试过去噪滤波，无效）。只影响 CGFM 的地图和 frontier，不影响雷达地形图和避障。
- **Jetson 的 WiFi 网卡驱动偶尔卡死**：`wlan0` 显示已连接但收发都不通，SSH 也会断。
- **VLM 服务卡死会让主线程阻塞数分钟**：客户端会重试多次；`--max-seconds` 只在两个 tick 之间检查，所以遥控器必须在手里。
- **首次 YOLO-World 调用**会触发 `ultralytics` 的 AutoUpdate（安装 `clip`、下载约 340 MB 权重，一次性）。
